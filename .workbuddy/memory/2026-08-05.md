### 紧急修复 — 页面空白无数据
- **根因**：`renderMyTasks()` 中 `全部视角` 分支的 forEach 回调内有一段上次编辑遗留的孤立 `else` 块（第572-581行），前面没有配对的 `if`，导致 JS 语法错误，`renderAll()` 静默失败
- **修复**：删除遗留的孤立 `else` 代码块

### 第二次紧急修复 — 阶段标签语法错误导致白屏
- **根因**：`cardHTML()` 中构建阶段标签那一行 `(done?'✓ ':(over?'⚠ ':'')+STAGES[i].name+'</span>';` 外层 `(` 没有闭合括号，JS 语法错误 → 整脚本不执行 → 白屏无数据
- **修复**：改为 `labelText=done?'✓ '+name:(over?'⚠ '+name:name)` 再拼 `<span>` 闭合，逻辑也更清晰
- **验证手段**：用 `node --check` 校验内联脚本语法 + 用 mock DOM 跑 `APP.init()/renderAll()/renderMyTasks()` 确认运行时无报错、DEMO 4 项目正常加载

### 第五次迭代 — 配套后端服务器
- **server.js**：Express 后端，JSON 文件存储 (data/projects.json)
- **API 端点**：
  - GET/PUT /api/projects（全量查询/替换）
  - GET/POST/PUT/DELETE /api/projects/:id（单项目 CRUD）
  - DELETE /api/projects?confirm=yes（清空全部）
  - GET /api/stats（统计）
- **前端双模式**：`API_BASE` 自动检测 — HTTP 访问时走 API 存服务器，文件打开时走 localStorage
- **loadData()** 在 API 模式用 fetch 异步加载，失败则回退 DEMO 数据
- **saveData()** 在 API 模式 PUT 全量数据到服务器
- **模式徽章**：顶部显示「服务器模式」（绿色）或「本地模式」（黄色）
- **数据迁移提取**：`_migrateStages()` 独立方法，API 和本地模式共用
- 依赖：express ^4.21.0
