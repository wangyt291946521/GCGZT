数据模型

📦 Project — 项目对象

字段类型必填说明
idstring*唯一标识，格式 P001
contractNostring*合同号，字母+数字，如 HT2024-088
namestring*项目名称
agentstring代理商
itemsstring设备清单描述
stagesobject*7 阶段进度对象

📌 Stage — 阶段对象（stages.{key}）

字段类型值范围说明
sstringpending / in-progress / done阶段状态
dsstringYYYY-MM-DD开始日期
destringYYYY-MM-DD截止日期（超期由前端自动判断）
hstring-处理人
nstring-备注
